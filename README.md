# SalaFinder
Sistema de reserva de salas, laboratorios y canchas universitarias.
Proyecto desarrollado para la materia **Ingeniería Web**.

## ¿Qué hace SalaFinder?
SalaFinder le permite a estudiantes y docentes consultar la disponibilidad
de espacios universitarios y hacer reservaciones en línea. Los administradores
pueden aprobar o rechazar solicitudes desde un panel dedicado (`/admin`).

## Instalación
1. `git clone https://github.com/DiegoColBdz/salafinder.git`
2. `cd salafinder`
3. `npm install`
4. `npm run dev`
5. Ir a `http://localhost:5173`

## Roles y accesos

| Rol     | Acceso |
|---------|--------|
| Student | Espacios, Calendario, Mis Reservas |
| Staff   | Panel Staff (no-shows) |
| Admin   | Panel Admin |
